## 开始游戏

双击 `index.html` 即玩。零依赖、零安装、纯本地,存档保存在浏览器里(关页面不丢)。

## 格斗系统(v0.2)

战斗是格斗式的 QTE 回合战,手感由你决定:

- **时机打击**:`attack` 后光标左右扫动,在中央 `││` 区间按 `Enter` = 完美破防(×2 伤害),按偏则伤害递减甚至落空
- **格挡窗口**:敌人每次出招都有 1.3~1.7 秒格挡窗口,及时按 `Enter` 伤害只剩 25% 并反充 8⚡
- **连招输入**:`combo`(15⚡)屏幕给出 4 个方向键序列,4 秒内依次按出 = 【连招终结】×2.6 伤害
- **自动模式**:输入 `auto on` 关闭所有 QTE 自动判定(手残友好),`auto off` 恢复

注意:QTE 期间不要切走标签页,回来时会判定为超时。

## 第一章流程(约 20-40 分钟)

1. `talk 白鸦` 接第一份活:去数据坟场终结「奎因」
2. 练级攒钱,`say 白鸦 交易` 买装备(裂解者v2 / 军规防火墙)
3. 从数据噬虫身上刷「密钥碎片」,`say 零姐 任务` 伪造门禁卡(LV3+)
4. `cd 公司塔·主机层`,输入两次 `kill 0`,决战 ROOT/0(建议 LV5)

死了不掉装备只掉 15% 钱,老针(夜色区)免费完全治疗。

## NIGHTSHELL ARENA 夜壳竞技场(v0.2)

终端之外的外传:Canvas 上的真·实时 1v1 格斗。信号被 ICE 屏蔽的地方,拳头就是最后的协议。

- **模式**:`[1]` 单人天梯(可选角色) · `[2]` 双人同屏对战(双方各选角色)
- **可选角色×4**:RUNNER(均衡)· 霓虹帮打手(力量,125 血/伤害 ×1.35)· ICE-巡逻者(敏捷,高速弹幕)· ROOT/0(霸体,必杀放出格式化波)
- **单人操作**:`A/D` 或 `←/→` 移动 · `W/↑/空格` 跳 · **双击方向**冲刺 · `S/↓` 格挡(减伤 85%) · `J` 快拳 · `K` 重脚(击飞) · `L` 必杀(气满) · `P` 暂停
- **双人操作**:P1 = `WASD` 移动/跳/格挡 + `F/G/H` 拳/脚/必杀;P2 = 方向键 + `,` `.` `/`(或 `1/2/3`)
- **天梯三连**:霓虹帮打手 → ICE-巡逻者(更快,会发波) → 零号守卫 ROOT/0(大体型 + 出招霸体 + 超必杀「格式化」贴地波——蓄力预警时跳起来,或格挡硬吃)
- **规则**:三局两胜,每回合 60 秒;打人攒气、挨打也攒气;KO 有慢镜头;切走页面自动暂停
- **彩蛋**:会自动读取 RPG 存档的代号作为拳手名;RPG 终端里输入 `arena` 可直接弹出竞技场
- 调试钩子:控制台 `window.__ar()` 看状态,`window.__arCheat` 有无敌/跳关(测试用)

## 技术说明

- 单文件×2(index.html 约 1100 行 RPG + arena.html 约 700 行格斗),无框架、无素材、无网络请求
- 音效由 WebAudio 实时合成(`sound off` 可关)
- CRT 扫描线 / 赛博雨 / 辉光字体全部 CSS + Canvas 实现
- QTE 动画用 setInterval 驱动;竞技场游戏逻辑用 Web Worker 计时器驱动(后台标签页 rAF 与 setTimeout 都会被节流,Worker 不会)——这是两次实测踩出来的经验
- 控制台输入 `window.__ns()` 可查看内部状态(调试用)
